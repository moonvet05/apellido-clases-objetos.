
# Sistema de Registro de Productos

- Nombre: Thomas Jesus Guerrero Vizcaino

## Descripción del programa
Este programa permite registrar productos mediante la consola.
Utiliza programación orientada a objetos en C# para almacenar
y mostrar la información de cada producto.

## Datos de entrada
El programa solicita al usuario los siguientes datos mediante el teclado:

- Código numérico del producto.
- Nombre del producto.
- Cantidad de unidades disponibles.
- Precio de cada unidad.

## Datos que procesa
El programa realiza las siguientes operaciones:

- Verifica que el nombre del producto no esté vacío.
- Comprueba que el precio sea mayor que cero.
- Valida que la cantidad no sea negativa.
- Calcula el valor total multiplicando el precio por la cantidad.
- Crea objetos utilizando la clase Producto.
- Almacena los productos válidos en una lista.
- Permite registrar hasta tres productos.

## Datos de salida
Al finalizar, el programa muestra:

- Código de cada producto.
- Nombre de cada producto.
- Cantidad de unidades.
- Precio de cada producto.
- Valor total de cada producto.
- Mensajes de error cuando se introducen datos incorrectos.
- Cantidad total de productos registrados.
