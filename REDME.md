
# Sistema de Registro de Productos

## Datos del autor
- Nombre: Thomas Jesus Guerrero Vizcaino

## Descripción del programa
Este programa permite registrar productos mediante la consola.
Utiliza programación orientada a objetos en C# para almacenar
y mostrar la información de cada producto.

## Datos de entrada
- Código del producto.
- Nombre del producto.
- Cantidad de productos.
- Precio del producto.

## Datos que procesa
- Valida que el nombre no esté vacío.
- Comprueba que el precio sea mayor que cero.
- Comprueba que la cantidad no sea negativa.
- Calcula el valor total multiplicando el precio por la cantidad.
- Almacena los productos registrados en una lista.

## Datos de salida
- Código del producto.
- Nombre del producto.
- Cantidad.
- Precio.
- Valor total de cada producto.
- Cantidad de productos registrados.
